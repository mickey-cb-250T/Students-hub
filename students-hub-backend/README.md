# Students Hub — Full Project

## Backend

```bash
cd students-hub-backend
npm install
npm run dev
```

API: http://localhost:5000

## Frontend

Your existing `CampusHub.tsx` is included at:

```text
students-hub-frontend/src/components/CampusHub.tsx
```

Place it inside your React/Framer project and connect it to the backend using the API endpoints in the backend README.

Change `JWT_SECRET` in `.env` before deployment.
